A tiny program that writes a single 143-character line to a file. It does one thing and nothing else: it puts the line below into `entry.txt`, ready to be read aloud.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. Set the `MAKEFUN_OUTPUT_DIR` environment variable to write `entry.txt` into a different directory instead. The program uses only the Python standard library, and its output is deterministic: running it twice produces byte-identical files.

## The line

> The boy who could not say his own name without stopping said it clean through at the register, and the cashier answered it like any other name.
