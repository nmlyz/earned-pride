A tiny program that writes a single line of quiet, earned pride to a file. The line is 143 characters: a boy who cannot say his own name without stopping says it clean through at the register, and the cashier answers it like any other name.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, no network, deterministic: two runs produce byte-identical output.

## The line

> The boy who could not say his own name without stopping said it clean through at the register, and the cashier answered it like any other name.
